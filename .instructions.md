# MP3 Maker - Agent Instructions

## Project Overview
This is an educational MP3 converter app built step by step to learn Python and web components.
The core file is `mp3_maker.py` which grows incrementally with each step.

## Development Roadmap (build in order)
1. **YouTube to MP3** - Single file download/convert using `yt-dlp` + `ffmpeg`
2. **Spotify to MP3** - Single file using `spotdl` or Spotify API fallback to yt-dlp
3. **Quality settings** - Configurable bitrate, sample rate, format options
4. **Search by artist/song** - Find Spotify/YouTube links from artist + song name
5. **Batch processing** - Process lists of links or artist-name entries from file
6. **API layer** - FastAPI REST API so other files/services can use mp3_maker
7. **Web frontend** - Browser UI that calls the API to create MP3 files
8. **Docker container** - Containerized solution with docker-compose
9. **Windows executable** - Standalone `.exe` using PyInstaller
10. **Linux executable** - Standalone Linux binary using PyInstaller

## Coding Conventions
- **Comments**: Add clear comments explaining what each section does and why
- **Step markers**: Mark code sections with `# === STEP N: description ===` comments
- **Incremental**: Each step builds on previous steps without breaking them
- **Imports**: Group at top, add new imports as steps are added
- **Functions**: Keep functions small and focused, one responsibility each
- **Error handling**: Add user-friendly error messages with context

## File Structure (grows with steps)
```
mp3_maker.py          # Core converter logic (Steps 1-5)
requirements.txt      # Python dependencies (updated each step)
README.md             # Full documentation and roadmap
api.py                # FastAPI API layer (Step 6)
static/               # Web frontend files (Step 7)
  index.html
  style.css
  app.js
Dockerfile            # Container build (Step 8)
docker-compose.yml    # Container orchestration (Step 8)
mp3_maker.spec        # PyInstaller spec (Steps 9-10)
tests/                # Tests added as features grow
```

## Key Dependencies
- `yt-dlp` - YouTube downloading
- `ffmpeg` - Audio conversion (system dependency, not pip)
- `spotdl` - Spotify downloading (Step 2+)
- `fastapi` + `uvicorn` - API server (Step 6+)
- `pyinstaller` - Executable building (Steps 9-10)

## Important Notes
- ffmpeg must be installed on the system PATH for audio conversion
- Spotify features require a Spotify API client ID/secret
- Each step should be testable independently from the command line
- The user is learning — explain decisions in comments, not just what the code does
